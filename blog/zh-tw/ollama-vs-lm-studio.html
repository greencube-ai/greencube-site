哪個更快？

兩者底層執行的都是 llama.cpp 系列的開源引擎，所以在同一臺電腦上，用同一個模型檔案、同樣的設定，速度大部分由硬體決定。我們沒有把這兩個應用程式放在一起計時，所以不會說誰贏。我們在 10 臺電腦上用 GreenCube 實測過的，是最影響速度的幾件事：

  • 模型能否裝進顯示卡。同一個 12B 模型完全在 8 GB 顯示卡上時每秒輸出 35.6 個 token，有一部分不在顯示卡上時只有 5.9 個：慢了 6 倍。
  • 顯示卡還是處理器。同一臺桌上型電腦上的同一個 AI：只用處理器每秒 5 個 token，用 RX 5700 XT 每秒 72 個。
  • 顯示卡有多新。四張 8 GB 顯示卡跑同一個模型，從每秒約 11 個到 72 個 token 不等。

所以無論用哪個應用程式，都要挑一個裝進你的顯示記憶體後還剩約 1.5 GB 的模型：哪個模型適合你的電腦。

常見問題

Ollama 和 LM Studio 哪個更快？

在同一臺電腦上，用同一個模型、同樣的設定，速度主要由你的硬體決定：兩者底層執行的都是開源的 llama.cpp 系列引擎。最影響速度的是模型能否完整裝進你的顯示卡。我們沒有把這兩個應用程式放在一起計時，所以不會說哪個更快。

Ollama 和 LM Studio 有什麼區別？

Ollama 是開源的（MIT），圍繞命令列和本地 API 打造，2025 年 7 月起在 Windows 和 Mac 上有桌面聊天視窗。LM Studio 是閉源的桌面應用程式，有聊天視窗、模型搜尋和本地 OpenAI 式伺服器，工作中也可免費使用。

新手用 Ollama 還是 LM Studio 更好？

如果你想在視窗裡瀏覽和下載模型，選 LM Studio。對想要背景服務和 API 的開發者來說，Ollama 更簡單。如果你根本不想挑模型，GreenCube（Windows，一次付清 9.99 歐元）會為你的電腦選一個。

Ollama 或 LM Studio 能在 Intel Mac 上用嗎？

Ollama 的文件列出了 Intel Mac，只能用 CPU，需要 macOS 14 或更高版本。LM Studio 需要搭載 Apple 晶片的 Mac。

Ollama 和 LM Studio 會把資料傳到網路上嗎？

LM Studio 表示，在本地執行時不會傳輸任何訊息或文件，也沒有遙測；檢查更新和下載模型會聯網。Ollama 表示在本地它看不到你的提示詞，但可能會收集有限的裝置和使用後設資料。如果你選擇雲端模型，兩者也都能用。
