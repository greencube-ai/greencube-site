Ollama 和 LM Studio 對比：有什麼區別，哪個更快（2026 年）

作者：Hector Gras · 2026年10月28日

Ollama 是開源的（MIT），為開發者而做：一個命令列、一個本地 API，以及 2025 年 7 月起加入的簡單聊天視窗。LM Studio 是閉源的桌面應用程式，有完整的聊天視窗、模型瀏覽器和本地伺服器，工作用途也免費。至於速度，主要取決於你的硬體，以及模型裝不裝得進你的顯示卡，而不是你選了這兩個裡的哪一個。

下面的事實都來自兩個應用程式自己的網站、說明文件和隱私權頁面，於 2026 年 10 月 21 日和 23 日查核。我在做 GreenCube，它會在最後以第三個選項出現，所以看我的意見時請把這點考慮進去。

哪個比較快？

兩者底層跑的都是 llama.cpp 系列的開源引擎。所以在同一台電腦上，用同一個模型檔案和同樣的設定，速度大多由硬體決定。我們沒有把這兩個應用程式並排計時，所以我不會宣布誰贏。

我們實際量過的，是在 10 台電腦上用 GreenCube 測出最影響速度的因素。這些數字來自我們的 GreenCube 測試，不是 Ollama 或 LM Studio，但同樣的硬體規則適用於任何應用程式：

  • 模型能不能裝進顯示卡。同一個 12B 模型整個放在 8 GB 顯示卡上時每秒寫出 35.6 個 token，有部分不在顯示卡上時是 5.9 個，慢了 6 倍。
  • 顯示卡還是處理器。同一台桌機上的同一個 AI，用處理器每秒寫出 5 個 token，用 RX 5700 XT 則是 72 個。
  • 顯示卡有多新。四張 8 GB 顯示卡跑同一個模型，每秒從約 11 到 72 個 token 都有。

所以不管用哪一個應用程式，都要挑一個能裝進你的顯示記憶體、還剩約 1.5 GB 的模型。哪個模型適合你的電腦 會逐張顯示卡說明。

該選哪一個？

如果你是開發者，Ollama 是很自然的選擇：它是開源的，以背景服務執行，還有可以讓其他工具接上的 API。

如果你想要一個視窗和模型瀏覽器，LM Studio 讓你不必打開終端機，就能瀏覽、下載模型並聊天。

如果你用的是 Intel Mac，答案已經替你決定好了。LM Studio 裝不起來，Ollama 只能用處理器跑，所以會很慢。

如果你根本不想挑模型，這正是 GreenCube 補上的缺口。它是 Windows 版，一次付清 9.99 歐元，會讀取你的顯示卡和記憶體，挑出裝得下的模型。更多選擇請看 LM Studio 替代方案。

常見問題

Ollama 和 LM Studio 哪個比較快？

在同一台電腦上、用同一個模型和同樣的設定，速度主要由你的硬體決定：兩者底層跑的都是開源的 llama.cpp 系列引擎。最影響速度的，是模型能不能整個裝進你的顯示卡。我們沒有把這兩個應用程式並排計時，所以不會說哪個比較快。

Ollama 和 LM Studio 有什麼不同？

Ollama 是開源的（MIT），以命令列和本地 API 為核心，2025 年 7 月起在 Windows 和 Mac 上多了桌面聊天視窗。LM Studio 是閉源的桌面應用程式，有聊天視窗、模型搜尋和本地 OpenAI 式伺服器，工作用途也免費。

新手適合用 Ollama 還是 LM Studio？

如果你想在視窗裡瀏覽和下載模型，選 LM Studio。對想要背景服務和 API 的開發者來說，Ollama 比較單純。如果你根本不想挑模型，GreenCube（Windows，一次付清 9.99 歐元）會替你的電腦選一個。

Ollama 或 LM Studio 能在 Intel Mac 上用嗎？

Ollama 的文件列出了 Intel Mac，只能用處理器跑，需要 macOS 14 以上。LM Studio 需要搭載 Apple 晶片的 Mac。

Ollama 和 LM Studio 會把資料傳上網嗎？

LM Studio 表示在本地執行時不會傳送任何訊息或文件，也沒有遙測；檢查更新和下載模型會連網。Ollama 表示在本地它看不到你的提示詞，但可能會收集有限的裝置和使用中繼資料。如果你選用雲端模型，兩者都可以使用。
