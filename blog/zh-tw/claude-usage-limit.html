GreenCube 在你自己的電腦上幫你做簡報、記憶卡、圖表和圖片。私密，不聯網也能用。€9.99 (US$9.99)，一次付清。

Claude 有兩個使用限制：一個每 5 小時重置，一個每週重置一次。Free、Pro 和 Max 兩個都有。200 美元的 Ultra 方案在帳號通過驗證後只剩每週限制。Anthropic 沒有公布任何方案能傳幾則訊息，因為長對話、大檔案和比較強的模型會更快用完額度。

最近的改變

Max 20x 現在改名為 Ultra，價格一樣是 200 美元，訂閱者已自動轉過去。如果「20x」變成「10x」看起來像是縮水，其實不一定。原本的 20x 描述的是 5 小時的時段，而關於 10 月 30 日這次調整的報導指出，每週額度維持不變（Magica）。新名稱描述的是一週實際能用多少。

Ultra 也拿掉了 5 小時限制，但要等 Anthropic 驗證你的帳號之後。在那之前，「會套用一個暫時的限制」（Anthropic Help Center）。每週限制在所有方案上都保留。

什麼會更快用完額度

Anthropic 的說明頁面列出了計入的因素：「對話的長度和複雜程度、你使用的功能、你正在對話的 Claude 模型，以及你選擇的投入程度」（Anthropic Help Center）。

長對話是大宗。每則新訊息都會連同之前的對話一起被讀取，用 Anthropic 的話來說，觸發 Claude 自動脈絡管理的長對話會「消耗更多的使用額度」。大檔案也一樣：你附加的檔案越長，能傳的訊息就越少。最強的模型和高投入設定，每則訊息的消耗也比較多。

還有 Claude Code。它和 Claude 應用程式、Claude Desktop 共用一個限制，所以一段長時間的寫程式，可能就把你留給對話的那一週額度用光了。

什麼時候重置

工作階段限制每五小時重置一次。每週限制「在分配給你帳號的每週固定時間」重置，不管你什麼時候開始訂閱，這個時間都不變（Anthropic Help Center）。Anthropic 沒有公布具體時間，但你可以在 Claude 設定的「用量」裡看到自己的。

Anthropic 也表示它「可能會視情況調整使用限制以管理容量」。所以某一週很容易就碰到的限制，下一週的感覺可能不一樣。

用完了怎麼辦

  1. 等它重置。如果是 5 小時限制，幾個小時就到。如果是每週限制，到「用量」設定裡看是哪一天。
  2. 開一個新對話，只把重要的兩三行複製過去，不要拖著一長串對話繼續。
  3. 傳小一點的檔案：只傳你需要的那一章，不是整本書。
  4. 簡單的問題用輕量的模型，把最強的那個留給難題。
  5. 用多少付多少。Pro、Max 和 Ultra 可以開啟用量額度，超過限制後繼續使用。它們「以標準 API 費率計費」（Anthropic Help Center），所以費用取決於你傳了多少。
  6. 如果每週都碰到限制，就升級。Max 提供 Pro 5 倍的用量，Ultra 提供 Pro 10 倍的每週用量。

或者，把日常的工作搬到你自己的電腦上

之所以有使用限制，是因為每則訊息都在 Anthropic 的伺服器上跑，總得有人付這筆錢。在你自己電腦上跑的 AI 沒有計數器，因為沒有伺服器要付錢。

GreenCube 做的就是這件事，因為是我做的，所以看這部分時請把這點考慮進去。你只要下載一次，它就能對話、讀你的 PDF、產生圖片（產生圖片需要 12 GB 記憶體），沒有 5 小時限制也沒有每週限制，沒有網路也能用。

說清楚一點：要處理大型程式碼庫裡棘手的 bug，或一長段需要仔細推理的工作，Claude 是比較強的工具，筆電上的小模型取代不了它。本地 AI 幫得上忙的，是那些吃掉你額度的日常大量工作：整理筆記重點、改寫句子、隨口的問題、用 PDF 替自己出題。把這些搬到你的電腦上，把 Claude 的額度留給真正需要它的工作。

常見問題

我在 Claude 上可以傳幾則訊息？

Anthropic 沒有替任何方案給出數字。它表示這取決於你的訊息多長、附加了哪些檔案、對話多長，以及你使用的模型或功能。

Claude 的限制什麼時候重置？

有兩個限制。工作階段限制每五小時重置一次；每週限制則在 Anthropic 替你的帳號設定的固定日期和時間重置，跟你什麼時候訂閱無關。兩者都可以在 Claude 設定的「用量」裡看到。

Claude Code 和 Claude 應用程式共用限制嗎？

是的。Anthropic 表示 claude.ai、Claude Code 和 Claude Desktop 都計入同一個限制。

Claude Ultra 是什麼？

Max 20x 方案的新名稱：每月 200 美元，每週用量是 Pro 的 10 倍，通過驗證的帳號沒有五小時限制。Max（原本的 Max 5x）仍然是每月 100 美元，兩個限制都有。

有完全沒有使用限制的 AI 嗎？

有，就是在你自己電腦上跑的 AI，因為沒有伺服器要按訊息付費。GreenCube 就是其中之一：對話、檔案和圖片都沒有上限，沒有網路也能用，一次付清 9.99 歐元。代價是它跑的模型比 Claude 小，速度也取決於你的電腦。
