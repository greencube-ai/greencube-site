AI ของคุณเอง บนคอมของคุณเอง

GreenCube ทำสไลด์ แฟลชการ์ด แผนภาพ และรูปภาพให้คุณบนคอมพิวเตอร์ของคุณเอง เป็นส่วนตัว และใช้ได้โดยไม่ต้องต่อเน็ต €9.99 (US$9.99) จ่ายครั้งเดียว

ลองได้ที่นี่ →

Claude มีขีดจำกัดการใช้งานสองแบบ แบบหนึ่งรีเซ็ตทุก 5 ชั่วโมง อีกแบบรีเซ็ตสัปดาห์ละครั้ง แผน Free, Pro และ Max มีทั้งสองแบบ แผน Ultra ราคา 200 ดอลลาร์มีแค่ลิมิตรายสัปดาห์ เมื่อบัญชีของคุณได้รับการยืนยันแล้ว Anthropic ไม่ได้เปิดเผยว่าแต่ละแผนส่งข้อความได้กี่ข้อความ เพราะแชตยาว ไฟล์ใหญ่ และโมเดลที่เก่งกว่าจะใช้ลิมิตหมดเร็วกว่า

ลิมิตของแต่ละแผน

ราคาทุก 5 ชั่วโมงทุกสัปดาห์
Free0 ดอลลาร์มีจำกัดมีจำกัด
Pro20 ดอลลาร์ต่อเดือน (17 ดอลลาร์ต่อเดือนถ้าจ่ายรายปี)1x1x
Max100 ดอลลาร์ต่อเดือน5x ของ Pro5x ของ Pro และมีลิมิตรายสัปดาห์แยกสำหรับโมเดล Fable
Ultra (เดิมคือ Max 20x)200 ดอลลาร์ต่อเดือนไม่มี สำหรับบัญชีที่ยืนยันแล้ว10x ของ Pro

ข้อมูลนี้มาจากหน้าราคาของ Anthropic และหน้าช่วยเหลือเรื่องแผน Pro, Max และ Ultra ตรวจเมื่อวันที่ 6 พฤศจิกายน 2026 ราคาเป็นดอลลาร์สหรัฐ ยังไม่รวมภาษี "1x" และ "5x" เป็นคำของ Anthropic เอง ซึ่งอธิบายลิมิตเป็นจำนวนเท่าของ Pro ไม่เคยบอกเป็นจำนวนข้อความ

อะไรเปลี่ยนไปเมื่อไม่นานมานี้

ตอนนี้ Max 20x เปลี่ยนชื่อเป็น Ultra ราคาเท่าเดิม 200 ดอลลาร์ และสมาชิกถูกย้ายไปให้อัตโนมัติ ถ้า "20x" กลายเป็น "10x" ดูเหมือนถูกลด ก็อาจไม่ใช่ 20x แบบเดิมหมายถึงช่วง 5 ชั่วโมง และรายงานเกี่ยวกับการเปลี่ยนแปลงเมื่อวันที่ 30 ตุลาคมบอกว่าปริมาณรายสัปดาห์ยังเท่าเดิม (Magica) ชื่อใหม่บอกตามจริงว่าหนึ่งสัปดาห์ใช้ได้แค่ไหน

Ultra ยังตัดลิมิต 5 ชั่วโมงออกด้วย แต่หลังจากที่ Anthropic ยืนยันบัญชีของคุณแล้วเท่านั้น ก่อนหน้านั้น "จะมีลิมิตชั่วคราว" (Anthropic Help Center) ลิมิตรายสัปดาห์ยังอยู่ในทุกแผน

อะไรทำให้ลิมิตหมดเร็วขึ้น

หน้าช่วยเหลือของ Anthropic บอกว่าสิ่งที่นับคือ "ความยาวและความซับซ้อนของบทสนทนา ฟีเจอร์ที่คุณใช้ โมเดล Claude ที่คุณกำลังคุยด้วย และระดับ effort ที่คุณเลือก" (Anthropic Help Center)

แชตยาวคือตัวการใหญ่ ข้อความใหม่ทุกข้อความจะถูกอ่านพร้อมกับบทสนทนาก่อนหน้าทั้งหมด และบทสนทนายาวๆ ที่ทำให้ระบบจัดการบริบทอัตโนมัติของ Claude ทำงานจะ "ใช้ลิมิตการใช้งานของคุณมากขึ้น" ตามคำของ Anthropic ไฟล์ใหญ่ก็เหมือนกัน ไฟล์ที่แนบยิ่งยาว คุณยิ่งส่งข้อความได้น้อยลง โมเดลที่เก่งที่สุดและการตั้ง effort สูงก็ใช้มากขึ้นต่อข้อความ

แล้วยังมี Claude Code อีก มันใช้ลิมิตเดียวกับแอป Claude และ Claude Desktop ดังนั้นการเขียนโค้ดยาวๆ หนึ่งรอบอาจใช้โควตาทั้งสัปดาห์ที่คุณเก็บไว้สำหรับแชตจนหมด

รีเซ็ตเมื่อไหร่

ลิมิตเซสชันรีเซ็ตทุกห้าชั่วโมง ลิมิตรายสัปดาห์รีเซ็ต "ในเวลาคงที่ทุกสัปดาห์ที่กำหนดให้บัญชีของคุณ" และเวลานั้นไม่เปลี่ยนไม่ว่าคุณจะเริ่มสมัครเมื่อไหร่ (Anthropic Help Center) Anthropic ไม่ได้เปิดเผยเวลานี้ แต่คุณดูของตัวเองได้ในการตั้งค่าของ Claude ที่หัวข้อ Usage

Anthropic ยังบอกด้วยว่า "อาจปรับลิมิตการใช้งานตามดุลยพินิจเพื่อจัดการกำลังการรองรับ" ดังนั้นลิมิตที่คุณใช้จนเต็มได้ง่ายๆ ในสัปดาห์นี้ อาจรู้สึกต่างไปในสัปดาห์หน้า

ทำอย่างไรเมื่อใช้ลิมิตจนเต็ม

  1. รอให้รีเซ็ต ถ้าเป็นลิมิต 5 ชั่วโมง ก็อีกไม่กี่ชั่วโมง ถ้าเป็นลิมิตรายสัปดาห์ ดูวันในการตั้งค่า Usage
  2. เริ่มแชตใหม่ แล้วคัดลอกแค่สองสามบรรทัดที่สำคัญไป แทนที่จะลากบทสนทนายาวๆ ไปด้วย
  3. ส่งไฟล์ที่เล็กลง แค่บทที่คุณต้องใช้ ไม่ใช่ทั้งเล่ม
  4. ใช้โมเดลที่เบากว่ากับคำถามง่ายๆ และเก็บโมเดลตัวท็อปไว้สำหรับคำถามยาก
  5. จ่ายตามการใช้งาน แผน Pro, Max และ Ultra เปิดเครดิตการใช้งานเพื่อใช้ต่อเกินลิมิตได้ โดย "คิดเงินตามอัตรา API มาตรฐาน" (Anthropic Help Center) ค่าใช้จ่ายจึงขึ้นอยู่กับว่าคุณส่งมากแค่ไหน
  6. อัปเกรด ถ้าคุณใช้จนเต็มทุกสัปดาห์ Max ให้ใช้งานได้ 5 เท่าของ Pro ส่วน Ultra ได้ 10 เท่าของปริมาณรายสัปดาห์ของ Pro

หรือย้ายงานประจำวันมาไว้บนคอมของคุณเอง

ลิมิตการใช้งานมีอยู่เพราะทุกข้อความรันบนเซิร์ฟเวอร์ของ Anthropic และต้องมีคนจ่ายค่าเซิร์ฟเวอร์ AI ที่รันบนคอมของคุณเองไม่มีตัวนับ เพราะไม่มีเซิร์ฟเวอร์ให้ต้องจ่าย

นั่นคือสิ่งที่ GreenCube ทำ และเพราะผมเป็นคนทำมัน อ่านส่วนนี้โดยคิดถึงข้อนี้ไว้ด้วย คุณดาวน์โหลดครั้งเดียว แล้วมันจะแชต อ่าน PDF และสร้างรูปภาพ (ต้องมี RAM 12 GB) โดยไม่มีลิมิต 5 ชั่วโมงหรือรายสัปดาห์ แม้ไม่มีอินเทอร์เน็ต

ความฉลาดหนึ่งใน AI ที่เก่งที่สุดที่มีอยู่โมเดลเล็ก (Gemma 4) ที่ใส่ในคอมทั่วไปได้ ดีสำหรับการเรียน การเขียน และคำถามในชีวิตประจำวัน อ่อนกว่าในการใช้เหตุผลที่ยากและโค้ดขนาดใหญ่
ความเร็วเร็วบนทุกอุปกรณ์ขึ้นอยู่กับคอมของคุณ 5 ถึง 7 โทเคนต่อวินาทีบนแล็ปท็อป 8 GB 14 ถึง 18 บนแล็ปท็อป 16 GB และ 37 ถึง 76 บนคอมเกมส่วนใหญ่ในการทดสอบของเรา

พูดให้ชัด สำหรับบั๊กยากๆ ในโค้ดเบสขนาดใหญ่หรือการใช้เหตุผลยาวๆ อย่างรอบคอบ Claude คือเครื่องมือที่เก่งกว่า และโมเดลเล็กบนแล็ปท็อปแทนมันไม่ได้ ที่ AI ในเครื่องช่วยได้คืองานจำนวนมากในแต่ละวันที่กินลิมิตของคุณ สรุปโน้ต เรียบเรียงใหม่ คำถามสั้นๆ ทดสอบตัวเองจาก PDF ย้ายงานพวกนั้นมาไว้บนคอมของคุณ แล้วเก็บลิมิตของ Claude ไว้สำหรับงานที่ต้องใช้มันจริงๆ

คำถาม

ส่งข้อความใน Claude ได้กี่ข้อความ?

Anthropic ไม่ได้ให้ตัวเลขสำหรับแผนไหนเลย บอกแค่ว่าขึ้นอยู่กับความยาวของข้อความ ไฟล์ที่คุณแนบ ความยาวของแชต และโมเดลหรือฟีเจอร์ที่คุณใช้

ลิมิตของ Claude รีเซ็ตเมื่อไหร่?

มีสองลิมิต ลิมิตเซสชันรีเซ็ตทุกห้าชั่วโมง ส่วนลิมิตรายสัปดาห์รีเซ็ตในวันและเวลาคงที่ที่ Anthropic กำหนดให้บัญชีของคุณ ไม่ว่าคุณจะสมัครตอนไหน ดูได้ทั้งสองอย่างในการตั้งค่าของ Claude ที่หัวข้อ Usage

Claude Code ใช้ลิมิตร่วมกับแอป Claude ไหม?

ใช่ Anthropic บอกว่า claude.ai, Claude Code และ Claude Desktop นับรวมในลิมิตเดียวกันทั้งหมด

Claude Ultra คืออะไร?

ชื่อใหม่ของแผน Max 20x ราคา 200 ดอลลาร์ต่อเดือน ใช้งานรายสัปดาห์ได้ 10 เท่าของ Pro และไม่มีลิมิตห้าชั่วโมงสำหรับบัญชีที่ยืนยันแล้ว ส่วน Max (Max 5x เดิม) ยังราคา 100 ดอลลาร์ต่อเดือนและมีทั้งสองลิมิต

มี AI ที่ไม่มีลิมิตการใช้งานเลยไหม?

มี คือ AI ที่รันบนคอมของคุณเอง เพราะไม่มีเซิร์ฟเวอร์ที่ต้องจ่ายค่าข้อความแต่ละข้อความ GreenCube เป็นหนึ่งในนั้น ไม่จำกัดแชต ไฟล์ หรือรูปภาพ ใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต ราคา 9.99 ยูโรจ่ายครั้งเดียว ข้อแลกคือมันรันโมเดลที่เล็กกว่า Claude และความเร็วขึ้นอยู่กับคอมของคุณ
