为什么有人在找 Open WebUI 的替代品

Open WebUI 是一个用 pip（Python 3.11）或 Docker 安装的自托管聊天页面，通常运行在 Ollama 或兼容 OpenAI 的 API 之类的引擎之上（文档）。它功能很强：能读文档，能“完全离线”运行，还有一个可选内置 llama.cpp 引擎的桌面应用（GitHub）。我们最常听到的另寻他处的原因有三个：

  • 许可证。现在是“Open WebUI License”：BSD 式条款，外加一条不得删除或替换“Open WebUI”品牌标识的条款，除非你在任意连续 30 天内的最终用户不超过 50 人、获得书面许可或拥有企业许可证（LICENSE）。
  • 部署。需要一台服务器、Docker 或 Python 环境，外加一个单独运行模型的引擎。
  • 是否合适。有人想要更大的（全公司搜索、权限管理），有人想要更小的（一台电脑上一个应用）。

哪个适合你？

给团队用的自托管聊天页面

LibreChat 是最接近的替换：MIT 许可证、Docker、多用户登录和管理面板，可连接云端 API 或你自己的引擎。如果主要任务是根据公司的文档和应用回答问题，选 Onyx（MIT 的 Community Edition，或托管版每用户每月 20 美元）。如果你最需要的是和文档聊天，选 AnythingLLM 的 Docker 版本。如果你想要智能体，又不介意它的许可证条件，选 LobeHub。

只有你自己，一台电脑，不用 Docker

LM Studio 和 Jan 像普通应用一样安装，自己运行模型；两者都能为其他工具提供本地 OpenAI 式 API。Msty 混合使用本地引擎和云端模型。GreenCube（Windows）会挑选并下载适合你电脑的模型，能读 PDF 和照片，还能生成图片，一次付清 9.99 欧元。

你喜欢折腾，想要完全掌控

text-generation-webui 支持多个后端（llama.cpp、ExLlamaV3、Transformers），并表示运行时“零遥测”。llama.cpp 自己的服务器给你一个没有任何多余东西的浏览器聊天页面。基于 llama.cpp 的单文件 .exe 程序 KoboldCpp 也是一个选择（GitHub）。

你想在手机上用同样的聊天

Chatbox 有桌面和手机应用，可以用 Ollama 运行本地模型。Open WebUI 本身也能作为网页应用添加到手机主屏幕。

常见问题

最好的 Open WebUI 替代品是什么？

取决于你为什么离开。想要给团队用的自托管聊天页面：LibreChat（MIT，Docker）。想搜索公司的文档：Onyx。一个人在一台电脑上用、不想用 Docker：LM Studio、Jan、Msty 或 text-generation-webui，它们自己运行模型。GreenCube（Windows，一次付清 9.99 欧元）会自动为你的电脑挑选模型。

Open WebUI 还是开源的吗？

它的许可证现在是"Open WebUI License"：BSD 式条款，外加一条不得删除或替换其品牌标识的条款，除非你在任意连续 30 天内的用户不超过 50 人、获得书面许可或拥有企业许可证。之前发布的代码保留原来的许可证。

有不需要 Docker 的 Open WebUI 替代品吗？

有。LM Studio、Jan、Msty、Chatbox 和 GreenCube 像普通应用一样安装；text-generation-webui 有解压即用的便携版；llama.cpp 的服务器自带网页聊天页面。

哪些 Open WebUI 替代品自己运行模型？

LM Studio、Jan、text-generation-webui、llama.cpp 和 GreenCube 不需要单独的引擎就能运行模型。LibreChat、Onyx、LobeHub 和 Chatbox 连接到 Ollama 之类的引擎或云端 API。

哪个替代品最适合团队？

LibreChat（MIT）支持 OAuth2、LDAP 和邮箱的多用户登录，还有管理面板。Onyx 增加了跨公司文档的搜索；它的 Business 套餐每用户每月 20 美元。AnythingLLM 的 Docker 版本也支持多用户。
