Open WebUI 替代品：核实了 11 个，从 LibreChat 到 LM Studio（2026 年 10 月）

作者：Hector Gras · 2026年10月23日

最好的 Open WebUI 替代品，取决于你为什么要换掉它。如果要给团队用的自托管聊天页面，LibreChat（MIT，Docker）是最接近的替换品，Onyx 则额外提供跨公司文档的搜索。如果只是你一个人、一台电脑，又想省掉 Docker 和单独的引擎，LM Studio、Jan 和 text-generation-webui 都能自己运行模型，Msty 则把本地引擎和云端模型整合到一个桌面应用里。

我在做 GreenCube，它是这 11 个之一，所以我没有给它们排名。每条事实都来自项目自己的网站、文档、价格页面或许可证，于 2026 年 10 月 21 日查阅，并在每一行附了链接。页面上没说的，我们写“未说明”；我们也没有拿这些应用互相跑分对比。

为什么有人要找 Open WebUI 的替代品

Open WebUI 是一个自托管的聊天页面，用 pip（Python 3.11）或 Docker 安装。它通常架在 Ollama 这样的引擎或兼容 OpenAI 的 API 之上（文档）。它是个能干的工具：能读文档，可以“完全离线”运行，还有一个桌面应用，可选内置 llama.cpp 引擎（GitHub）。

人们离开的第一个原因是许可证。它现在叫“Open WebUI License”：BSD 式条款，外加一条不得删除或替换“Open WebUI”品牌标识的条款，除非你在任意连续 30 天内的终端用户不超过 50 人、获得书面许可或拥有企业许可证（LICENSE）。

第二个原因是部署：要一台服务器、Docker 或 Python 环境，外加一个单独运行模型的引擎。第三个原因是合不合适。有些人想要更大的东西，带公司内搜索和权限管理；另一些人想要更小的，比如一台电脑上一个应用就够。

哪个适合你？

给团队用的自托管聊天页面

LibreChat 是最接近的替换品。它采用 MIT 许可证，在 Docker 里运行，自带多用户登录和管理面板，可以连接云端 API 或你自己的引擎。如果主要任务是根据公司的文档和应用回答问题，Onyx 就是为此而生的（MIT 社区版，或 Business 套餐每用户每月 20 美元）。如果你最需要的是与文档聊天，AnythingLLM 的 Docker 版很合适；LobeHub 则适合想用智能体、又不介意它许可证条件的人。

只有你一个人、一台电脑、不用 Docker

LM Studio 和 Jan 像普通应用一样安装，自己运行模型，两者都能为其他工具提供本地的 OpenAI 风格 API。Msty 把本地引擎和云端模型混在一起用。我做的 GreenCube 面向 Windows：它会挑选并下载适合你电脑的模型，能读 PDF 和照片、生成图片，一次付清 9.99 欧元。

你喜欢折腾，想完全自己掌控

text-generation-webui 支持多种后端（llama.cpp、ExLlamaV3、Transformers），并声称“零遥测”运行。llama.cpp 自带的服务器给你一个浏览器聊天页面，上面没有任何多余的东西。KoboldCpp 是基于 llama.cpp 的单个 .exe，也是一个选择（GitHub）。

你想在手机上用同样的聊天

Chatbox 有桌面和手机应用，可以用 Ollama 跑本地模型。不过也要知道，Open WebUI 本身就能作为网页应用添加到手机主屏幕上，所以单凭这一点可能不足以让你换掉它。

本地模型在普通电脑上有多快？

不管你选哪个界面，速度都来自你的硬件，因为模型运行在你的显卡或处理器上。我们在 10 台真实电脑上测了 GreenCube；其他应用没有在同样的机器上测过。

常见问题

最好的 Open WebUI 替代品是什么？

取决于你为什么离开。想要给团队用的自托管聊天页面：LibreChat（MIT，Docker）。想搜索公司的文档：Onyx。一个人在一台电脑上用、不想用 Docker：LM Studio、Jan、Msty 或 text-generation-webui，它们自己运行模型。GreenCube（Windows，一次付清 9.99 欧元）会自动为你的电脑挑选模型。

Open WebUI 还是开源的吗？

它的许可证现在是"Open WebUI License"：BSD 式条款，外加一条不得删除或替换其品牌标识的条款，除非你在任意连续 30 天内的用户不超过 50 人、获得书面许可或拥有企业许可证。之前发布的代码保留原来的许可证。

有不需要 Docker 的 Open WebUI 替代品吗？

有。LM Studio、Jan、Msty、Chatbox 和 GreenCube 像普通应用一样安装；text-generation-webui 有解压即用的便携版；llama.cpp 的服务器自带网页聊天页面。

哪些 Open WebUI 替代品自己运行模型？

LM Studio、Jan、text-generation-webui、llama.cpp 和 GreenCube 不需要单独的引擎就能运行模型。LibreChat、Onyx、LobeHub 和 Chatbox 连接到 Ollama 之类的引擎或云端 API。

哪个替代品最适合团队？

LibreChat（MIT）支持 OAuth2、LDAP 和邮箱的多用户登录，还有管理面板。Onyx 增加了跨公司文档的搜索；它的 Business 套餐每用户每月 20 美元。AnythingLLM 的 Docker 版本也支持多用户。
