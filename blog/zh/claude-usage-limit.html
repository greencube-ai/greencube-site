Claude 有两个使用限制：一个每 5 小时重置，一个每周重置一次。Free、Pro 和 Max 两个都有。200 美元的 Ultra 套餐在账户通过验证后只有每周限制。Anthropic 没有公布任何套餐能发多少条消息，因为长聊天、大文件和更强的模型会更快用完额度。

最近的变化

Max 20x 现在改名为 Ultra，价格还是 200 美元，订阅用户已自动转过去。如果“20x”变成“10x”看起来像是缩水，其实未必。原来的 20x 描述的是 5 小时窗口，而关于 10 月 30 日这次调整的报道称，每周额度保持不变（Magica）。新名字描述的是一周实际能用多少。

Ultra 也取消了 5 小时限制，但要等 Anthropic 验证你的账户之后。在那之前，“会适用一个临时限制”（Anthropic Help Center）。每周限制在所有套餐上都保留。

什么会更快用完额度

Anthropic 的帮助页面列出了计入的因素：“对话的长度和复杂程度、你使用的功能、你正在对话的 Claude 模型，以及你选择的投入程度”（Anthropic Help Center）。

长聊天是大头。每条新消息都会连同之前的对话一起被读取，用 Anthropic 的话说，触发 Claude 自动上下文管理的长对话会“消耗更多的使用额度”。大文件也一样：你附加的文件越长，能发的消息就越少。最强的模型和高投入设置每条消息的消耗也更多。

还有 Claude Code。它和 Claude 应用、Claude Desktop 共用一个限制，所以一次长时间的编程，可能就把你留给聊天的那一周额度用光了。

什么时候重置

会话限制每五小时重置一次。每周限制“在分配给你账户的每周固定时间”重置，无论你什么时候开始订阅，这个时间都不变（Anthropic Help Center）。Anthropic 没有公布具体时间，但你可以在 Claude 设置的“用量”里看到自己的。

Anthropic 还表示它“可能会酌情调整使用限制以管理容量”。所以某一周很容易就碰到的限制，下一周的感觉可能不一样。

用完了怎么办

  1. 等它重置。如果是 5 小时限制，几个小时就到。如果是每周限制，在“用量”设置里查看是哪一天。
  2. 开一个新聊天，只把重要的两三行复制过去，而不是拖着一长段对话继续。
  3. 发小一点的文件：只发你需要的那一章，而不是整本书。
  4. 简单的问题用轻量的模型，把最强的模型留给难题。
  5. 按量付费。Pro、Max 和 Ultra 可以开启用量额度，在超出限制后继续使用。它们“按标准 API 费率计费”（Anthropic Help Center），所以费用取决于你发了多少。
  6. 如果每周都碰到限制，就升级。Max 提供 Pro 5 倍的用量，Ultra 提供 Pro 10 倍的每周用量。

常见问题

我在 Claude 上能发多少条消息？

Anthropic 没有为任何套餐给出具体数字。它表示这取决于你的消息有多长、附加了哪些文件、聊天有多长，以及你使用的模型或功能。

Claude 的限制什么时候重置？

有两个限制。会话限制每五小时重置一次；每周限制在 Anthropic 为你的账户设定的固定日期和时间重置，与你何时订阅无关。两者都可以在 Claude 设置的“用量”里看到。

Claude Code 和 Claude 应用共用限制吗？

是的。Anthropic 表示 claude.ai、Claude Code 和 Claude Desktop 都计入同一个限制。

Claude Ultra 是什么？

Max 20x 套餐的新名字：每月 200 美元，每周用量是 Pro 的 10 倍，已验证的账户没有五小时限制。Max（原 Max 5x）仍然是每月 100 美元，两个限制都有。

有完全没有使用限制的 AI 吗？

有，就是在你自己电脑上运行的 AI，因为没有服务器按消息付费。GreenCube 就是其中之一：聊天、文件和图片都不设上限，不联网也能用，一次付清 9.99 欧元。代价是它运行的模型比 Claude 小，速度也取决于你的电脑。
