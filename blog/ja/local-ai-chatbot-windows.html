Windows 10・11でオフラインAI：PCに必要なもの、10台で計測

著者：Hector Gras · 2026年10月23日

RAMが8 GBあるWindows 10か11のPCなら、インターネットなしでAIチャットボットを動かせます。16 GBあるか、ゲーミング用のグラフィックボードがあれば快適です。アプリとAIモデルを一度ダウンロードすれば、あとはWi-Fiを切っても使えます。計測した10台のWindows PCでは、8 GBのノートPCで英語を読むのと同じくらいの速さ、ゲーミングPCではその何倍もの速さでした。

私は下で紹介するアプリのひとつ、GreenCubeを作っているので、私の意見はその点を割り引いて読んでください。ここでの速さはすべてGreenCubeで計ったものです。私たちがテストに使っているのがそれだからです。他のアプリは、それぞれの公式サイトに書かれている内容で比べています。

自分のPCに何が入っているかわからない場合は、Ctrl + Shift + Escを押してパフォーマンスを開き、メモリとGPUを見てください。または自分のグラフィックボードをチェッカーに入力すると、何が動くか、似た実際のPCでどれくらいの速さだったかがわかります。

以下の数字はすべて、2026年9月と10月に実際のWindows PCでGreenCubeを動かしたもので、ほとんどは実際のチャットでの値です。トークンは単語の断片で、英語を読む場合、たいていの人は1秒に約5トークン分を読みます。

唯一の例外は古いAMD RX 580で、毎秒約11トークンでした。それでも英語を読む速さよりは速いです。テストしたすべてのカードは、それぞれのページとともに自分のPCでAIは動く？にまとめています。

重い仕事をするのはグラフィックボード

同じWindowsのデスクトップPCで、同じAIがCPUでは毎秒5トークン、RX 5700 XTでは72トークンでした。AIを動かすのは、ほとんどがグラフィックボード向きの計算なので、最近のゲーミング用カードならどれでも大きな差が出ます。

どれだけ大きなAIが収まるかを決めるのは、RAMではなくカード自身のメモリ（VRAM）です。詳しくはモデルがカードに収まらなければならない理由にあります。

グラフィックボードがなくても、勉強とチャットには十分

Intelグラフィックスしかない普通の16 GBのノートPCで、説明と試験形式の問題3つからなる勉強用の答えが約20秒で完成しました。8 GBのノートPCでも、他のアプリがメモリを少し空けておいてくれれば、もっと遅いですが動きます（8 GBのテスト）。

Windows 10とWindows 11、どちら？

AIはどちらでも同じように動きます。大事なのはRAMとグラフィックボードで、Windowsのバージョンではないからです。ひとつ知っておきたいのは、MicrosoftがWindows 10のサポートを2025年10月14日に終了したことです。拡張セキュリティ更新に登録しない限り、Windows 10のPCにはもうセキュリティ更新が届きません。オフラインAIならどちらでもチャットはPCに残りますが、Windows自体を最新に保つ価値はやはりあります。

本当にオフラインのままか確認する方法

  1. 最初のダウンロードが終わったら、機内モードをオンにして（またはケーブルを抜いて）チャットしてみます。答えが返ってくれば、AIはPCの中で動いています。
  2. ネットワークを見張ります。Windows + Rを押してresmonと入力し、ネットワークタブを開きます。「ネットワーク活動のあるプロセス」に、チャット中にデータを送受信しているプログラムがすべて表示されます。
  3. アプリが何をオンラインに送ると書いているか読みます。GreenCubeは、有効化のために一度サインインし、AIとその更新をダウンロードします。オンライン検索（アプリを開くたびにオフで始まります）は、検索語を検索エンジンに送ります。それ以外は何も出ていきません。「チャット、ファイル、メモリー、画像を受け取ることはありません」。

WindowsのオフラインAIにできないこと

今日のニュースは知りません。モデルが知っているのは学習で覚えたことだけなので、最新のことにはウェブ検索が必要で、その部分はオンラインになります。

何でも最大級のクラウドAIに勝てるわけではありません。PCに収まるモデルは、勉強、文章書き、日常の質問はうまくこなしますが、一番難しい問題では、最大級のクラウドのモデルがまだ上です。

そして、速さはPC次第です。8 GBのノートPCは英語を読むのと同じくらいの速さで書き、ゲーミングPCならはるかに速く書きます。勉強に使うなら、オフラインAIが学生のためにできることに、PDF、学習ガイド、フラッシュカードの時間を載せています。

よくある質問

Windows 11でAIをオフラインで使えますか？

使えます。GreenCube、LM Studio、Jan、Ollama、GPT4AllなどのアプリはAIモデルを自分のPCで動かします。アプリとモデルのダウンロードに一度だけインターネットが必要で、その後はWi-Fiを切ってもチャットできます。

オフラインAIはWindows 10で動きますか？

動きます。GreenCube、Jan、MstyはWindows 10を対応OSとしています。MicrosoftはWindows 10のサポートを2025年10月14日に終了しました。AIは動き続けますが、拡張セキュリティ更新に登録しない限り、PCにセキュリティ更新は届きません。

Windows PCでローカルAIを動かすにはメモリがどれくらい必要ですか？

小さなモデルなら8 GBで足ります。8 GBのノートPCは実際のチャットで毎秒5〜7トークン、英語を読むのと同じくらいの速さで書きました。16 GBなら快適で、グラフィックボードなしの16 GBノートPCは毎秒14〜18トークンでした。

WindowsのローカルAIチャットボットにグラフィックボードは必要ですか？

必要ありませんが、大きく効きます。6 GB以上のカードを積んだゲーミングPCでは、ほとんどのカードで毎秒37〜76トークンを計測しました。同じPCのCPUだけの場合の何倍もの速さです。画像を作るにはRAMが12 GB以上必要です。

Windows用の無料オフラインAIはありますか？

あります。LM Studio、Jan、Ollama、GPT4All、AnythingLLMは無料で、モデルは自分で選んでダウンロードします。GreenCubeは9.99ユーロの買い切りで、PCに合うモデルを自動で選びます。
