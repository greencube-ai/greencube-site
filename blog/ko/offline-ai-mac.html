Mac에서 오프라인 AI: Apple Intelligence는 인터넷 없이 될까, 그리고 어떤 앱이 될까?

내 PC에서 돌아가는 나만의 AI

GreenCube는 내 컴퓨터에서 돌아갑니다. 사용 제한 없음, 구독 없음, 인터넷 없이도 작동. €9.99 (US$9.99), 한 번 결제.

여기서 바로 써 보기 →

네, Mac은 인터넷 없이 AI를 돌릴 수 있습니다. Apple 칩 Mac에서는 LM Studio, Jan, Ollama, GPT4All, Msty, AnythingLLM 모두 모델을 한 번 내려받은 뒤에는 오프라인으로 작동하고, 그중 LM Studio와 Jan이 시작하기 가장 쉽습니다. 오래된 Intel Mac에서는 목록이 Ollama 하나로 줄고, 그마저 프로세서로만 돕니다. Apple Intelligence는 일부만 오프라인으로 됩니다.

저도 오프라인 AI 앱인 GreenCube를 만들고 있지만 Windows 전용이라 여기 선택지에는 없습니다. 아래 내용은 모두 각 앱의 페이지에서 가져왔고, 2026년 10월 21일과 23일에 읽었습니다.

Mac용 오프라인 AI 앱, 확인 결과

'명시 안 됨'은 앱 페이지에 된다고도 안 된다고도 나와 있지 않다는 뜻입니다.

터미널 없이 평범한 앱 창을 원한다면 LM Studio나 Jan으로 시작하세요. 목록에서 모델을 골라 내려받고 채팅하면 됩니다. 명령줄이 편하다면 Ollama를 써 볼 만하고, 여기서 Intel Mac에서 돌아간다고 아직 약속하는 것은 Ollama뿐입니다. GPT4All의 마지막 릴리스는 2025년 2월이니, 고르기 전에 알아 두세요.

각 앱이 온라인으로 보내는 것은 개인정보 페이지를 바탕으로 오프라인 AI 챗봇 12개 비교에 정리했습니다. LM Studio를 떠나려는 거라면 LM Studio 대안을 보세요.

Apple Intelligence는 오프라인으로 될까?

일부만 됩니다. Apple은 Apple Intelligence가 요청을 먼저 Mac에서 처리하고, 더 무거운 요청은 자사 서버인 Private Cloud Compute로 보낸다고 하며, 여기에는 연결이 필요합니다(Apple). 선택 사항인 ChatGPT 확장도 인터넷이 필요합니다.

Apple은 어떤 기능이 항상 기기 안에서만 처리되는지 목록을 공개하지 않습니다. 그러니 정직한 방법은 단순한 것입니다. 비행기 모드를 켜고 관심 있는 기능을 써 보세요.

어떤 Mac이 로컬 AI를 잘 돌릴까?

대부분은 메모리가 결정합니다. Apple 칩은 프로세서와 그래픽이 메모리를 함께 쓰기 때문에 AI가 메모리 대부분을 쓸 수 있고, 16 GB 이상이면 여유롭습니다. 8 GB에서도 작은 모델은 됩니다. 다른 8 GB 컴퓨터와 마찬가지로 다른 앱을 먼저 닫기만 하면요.

Intel Mac은 프로세서로 Ollama만 돌릴 수 있으니 답이 느릴 거라고 생각하세요. 어떤 Mac이든 모델이 메모리에 들어가고 대화를 위한 공간이 남아야 하며, 들어가지 않는 더 큰 모델은 더 낫지 않습니다. 메모리에 들어가지 않는 모델은 훨씬 느리게 돕니다.

저희는 Windows PC에서 측정하기 때문에, 직접 잰 Mac 속도는 드릴 수 없습니다.

Windows PC라면?

Windows 10이나 11 PC도 있다면 GreenCube는 거기서 돌아갑니다. PC에 맞는 AI를 고르고, PDF와 사진을 읽고, 이미지를 만듭니다. 모두 오프라인이고 9.99유로 한 번입니다. 판매 중인 Mac 버전은 없습니다. 속도를 포함한 Windows 쪽 이야기는 Windows용 오프라인 AI, PC 10대에서 측정에 있습니다.

자주 묻는 질문

Mac에 가장 좋은 오프라인 AI는?

Apple 칩 Mac에서는 LM Studio(무료)와 Jan(무료, 오픈 소스)이 가장 쉽고, Ollama가 채팅 창이 있는 대표적인 명령줄 선택지입니다. Intel Mac에서는 Ollama 문서에 여전히 지원이 나와 있습니다. CPU 전용, macOS 14 이상입니다.

Apple Intelligence는 Mac에서 오프라인으로 작동하나요?

일부만 됩니다. Apple은 요청을 먼저 기기에서 처리하고, 더 어려운 요청은 인터넷이 필요한 Private Cloud Compute 서버로 보낸다고 합니다. ChatGPT 확장도 인터넷이 필요합니다. Apple은 어떤 기능이 오프라인으로 되는지 목록을 내놓지 않으니, 확실한 방법은 비행기 모드를 켜고 직접 해 보는 것입니다.

Intel Mac에서 로컬 AI를 돌릴 수 있나요?

네, 제한이 있습니다. LM Studio와 Jan은 Apple 칩이 필요합니다. Ollama는 Intel Mac(x86)을 CPU 전용으로, macOS 14 Sonoma 이상에서 지원한다고 하니 느릴 거라고 생각하세요.

GreenCube는 Mac에서 되나요?

아니요, GreenCube는 Windows 10과 11용입니다. Mac에서는 이 페이지에 있는 앱 중 하나를 쓰세요.
