Open WebUI 대안: LibreChat부터 LM Studio까지 11개 확인(2026년 10월)

글쓴이 Hector Gras · 2026년 9월 15일

짧은 답: Open WebUI를 떠나는 이유에 달려 있습니다. 팀용 셀프 호스팅 채팅 페이지라면 가장 가까운 대체품은 LibreChat(MIT, Docker)이고, Onyx는 회사 문서 전체 검색을 더합니다. 컴퓨터 한 대에서 나 혼자 쓰고, Docker나 별도 엔진이 싫다면 LM Studio, Jan, Msty, text-generation-webui가 모델을 직접 돌립니다. GreenCube(Windows, 9.99유로 한 번)도 마찬가지이고, 내 PC에 맞는 모델을 고릅니다.

11각 프로젝트의 페이지로 확인한 대안. 2026년 10월 21일
50사용자: 이를 넘으면 Open WebUI 라이선스는 브랜드 유지를 요구합니다
511개 중 별도 엔진 없이 모델을 직접 돌리는 것

사람들이 Open WebUI 대안을 찾는 이유

Open WebUI는 pip(Python 3.11)이나 Docker로 설치하는 셀프 호스팅 채팅 페이지로, 보통 Ollama나 OpenAI 호환 API 같은 엔진 위에서 돌아갑니다(문서). 기능이 많아서 문서를 읽고, "완전히 오프라인으로" 돌릴 수 있으며, llama.cpp 엔진을 선택적으로 내장한 데스크톱 앱도 있습니다(GitHub). 다른 걸 찾는 이유로 가장 자주 듣는 건 세 가지입니다:

  • 라이선스. 이제 "Open WebUI License"입니다. BSD 방식의 조건에, 30일 동안 최종 사용자가 50명 이하이거나, 서면 허가가 있거나, 기업 라이선스가 있는 경우가 아니면 "Open WebUI" 브랜드 표시를 지우거나 바꿀 수 없다는 조항이 더해졌습니다(LICENSE).
  • 설치. 서버, Docker나 Python 환경, 그리고 모델용 별도 엔진이 필요합니다.
  • 용도. 더 큰 것(회사 전체 검색, 권한 관리)을 원하는 사람도 있고, 더 작은 것(PC 한 대에 앱 하나)을 원하는 사람도 있습니다.

대안 11개 비교

모든 정보는 각 행에 링크한 프로젝트의 웹사이트, 문서, GitHub 페이지에서 2026년 10월 21일에 읽은 것입니다. 페이지에 없는 내용은 "명시 안 됨"이라고 적었습니다. 이 앱들끼리 벤치마크를 하지는 않았습니다.

앱무엇인가라이선스와 가격설치 방법모델을 직접 돌리나?내 문서
LibreChat(GitHub)여러 AI 제공자를 위한 셀프 호스팅 채팅 페이지. 다중 사용자 로그인(OAuth2, LDAP, 이메일)과 관리자 패널MIT, 무료Docker(문서에 따르면 약 5분), npm 또는 Helm. "네이티브 데스크톱 앱이 아님"(문서)아니요: 클라우드 API나 Ollama, koboldcpp 같은 로컬 엔진에 연결예, 파일과 채팅, 파일 검색
Onyx(GitHub)AI 채팅과 팀 문서·앱 전체 검색Community Edition은 MIT, 무료. Business는 사용자당 월 20달러, 연간 결제(가격)설치 스크립트, Docker, Kubernetes. 1 GB 미만의 Lite 모드는 문서를 색인하지 못함아니요: Ollama, vLLM 등이나 클라우드 API에 연결예, 주된 용도. 네트워크와 완전히 분리해 돌릴 수 있음(사이트)
LobeHub(옛 LobeChat, GitHub)에이전트와 채팅 플랫폼, 셀프 호스팅 또는 호스팅LobeHub Community License(파생물에 추가 조건이 있는 Apache 2.0). 호스팅 플랜은 무료부터(가격)Docker, 또는 클라우드 호스트에 원클릭 배포아니요: AI 제공자에 연결읽은 페이지에 설명 없음
AnythingLLM(GitHub)내 문서와 채팅. 데스크톱 앱 또는 팀 서버MIT, 데스크톱 무료데스크톱 설치 프로그램(Windows, Mac, Linux), 또는 다중 사용자용 Docker로컬(Ollama, LM Studio)과 클라우드의 여러 제공자에 연결예: PDF, TXT, DOCX
Chatbox(GitHub)여러 AI 모델을 위한 데스크톱·모바일 채팅 클라이언트Community Edition은 GPL-3.0. 호스팅 플랜은 Lite 월 3.99달러부터 Pro+ 월 39.99달러까지(가격)Windows, Mac, Linux 설치 프로그램. iPhone과 Android 앱아니요: 클라우드 API, 자체 호스팅 서비스, 로컬 모델은 Ollama예, 로컬 지식 베이스
LM Studio(사이트)채팅과 로컬 OpenAI 방식 서버를 갖춘 데스크톱 앱무료, 업무용도 가능. 비공개 소스설치 프로그램. Windows는 AVX2, Mac은 Apple 칩 필요(요구 사양)예예: PDF, DOCX, TXT
Jan(GitHub)데스크톱 채팅 앱과 로컬 OpenAI 호환 서버Apache 2.0, 무료Windows, Mac, Linux 설치 프로그램예. 클라우드 모델도 선택 가능예: PDF, Office 파일
Msty(사이트)로컬 엔진과 클라우드 모델을 한데 모은 데스크톱 앱무료 플랜 있음. Aurum은 연 149달러 또는 한 번 349달러(가격). 라이선스 명시 안 됨Windows, Mac, Linux 설치 프로그램로컬 엔진(MLX, llama.cpp, Ollama)과 호스팅 제공자 사용예, Knowledge Stacks
text-generation-webui(현재 "textgen", GitHub)모델용 로컬 웹 UI, OpenAI/Anthropic 호환 API 포함AGPL-3.0, 무료포터블 버전: 압축 풀고 실행. 또는 원클릭 스크립트, Conda, Docker예: llama.cpp, ExLlamaV3, Transformers 등예: PDF, DOCX, 텍스트 첨부
llama.cpp 서버(GitHub)엔진 그 자체. 서버에 브라우저 채팅 페이지 포함MIT, 무료설치 스크립트, 미리 빌드된 바이너리, Docker, 또는 소스에서 빌드예명시 안 됨
GreenCube(사이트)한 사람을 위한 데스크톱 앱: 채팅, PDF로 공부, 코드, 이미지9.99유로 한 번. 비공개 소스Windows 10과 11 설치 프로그램. 서버나 Docker 불필요예, 그리고 내 PC에 맞는 모델을 고름예: PDF, 노트, 사진

나에게 맞는 건?

팀용 셀프 호스팅 채팅 페이지

LibreChat이 가장 가까운 대체품입니다. MIT 라이선스, Docker, 다중 사용자 로그인과 관리자 패널이 있고, 클라우드 API나 내 엔진에 연결합니다. 주된 일이 회사 문서와 앱에서 답을 찾는 것이라면 Onyx(MIT Community Edition, 또는 호스팅으로 사용자당 월 20달러). 문서와의 채팅이 가장 중요하다면 AnythingLLM의 Docker 버전. 에이전트를 원하고 라이선스 조건이 괜찮다면 LobeHub.

컴퓨터 한 대에서 나 혼자, Docker 없이

LM Studio와 Jan은 일반 앱처럼 설치되고 모델을 직접 돌립니다. 둘 다 다른 도구를 위해 로컬 OpenAI 방식 API도 제공할 수 있습니다. Msty는 로컬 엔진과 클라우드 모델을 섞어 씁니다. GreenCube(Windows)는 내 PC에 맞는 모델을 골라 내려받고, PDF와 사진을 읽고, 이미지도 만들며, 9.99유로 한 번 결제입니다.

만지작거리는 걸 좋아하고 완전히 제어하고 싶다면

text-generation-webui는 여러 백엔드(llama.cpp, ExLlamaV3, Transformers)를 지원하고 "텔레메트리 없이" 돌아간다고 합니다. llama.cpp 자체 서버는 군더더기 없는 브라우저 채팅 페이지를 줍니다. llama.cpp 기반의 단일 .exe인 KoboldCpp도 선택지입니다(GitHub).

같은 채팅을 휴대폰에서도 쓰고 싶다면

Chatbox는 데스크톱과 휴대폰 앱이 있고, 로컬 모델에 Ollama를 쓸 수 있습니다. Open WebUI 자체도 웹 앱으로 휴대폰 홈 화면에 추가할 수 있습니다.

평범한 PC에서 로컬 모델은 얼마나 빠를까?

어떤 인터페이스를 고르든 속도는 하드웨어에서 나옵니다. 모델은 그래픽카드나 CPU에서 돌아가니까요. 실제 PC 10대에서 GreenCube를 측정했습니다(같은 기기에서 다른 앱은 측정하지 않았습니다):

내 PC출력
그래픽카드 없는 8 GB 노트북5–7 토큰/초, 대략 읽는 속도
그래픽카드 없는 16 GB 노트북14–18 토큰/초
6 GB 이상 카드의 게이밍 PC대부분의 카드에서 37–76 토큰/초

카드별 숫자는 내 PC에서 AI가 돌아갈까?에, 원본 데이터는 측정 방법에 있습니다. 개인정보와 온라인으로 나가는 것 기준으로 데스크톱 앱을 비교하려면 오프라인 AI 챗봇 12개 비교를 보세요.

확인 방법

2026년 10월 21일, 리뷰나 다른 목록이 아니라 각 프로젝트의 GitHub 페이지, 문서, 가격 페이지, 라이선스를 직접 읽고, 각 정보의 출처 페이지를 링크했습니다. 페이지끼리 맞지 않을 때(LobeHub README 배지는 Apache 2.0이지만 LICENSE 파일은 조건을 더함)는 라이선스 파일을 따랐습니다. 저희가 GreenCube를 만들기 때문에, 누구나 확인할 수 있는 사실만 담았고 앱 순위는 매기지 않았습니다. 매달 다시 확인하고 위의 날짜를 업데이트합니다.

자주 묻는 질문

Open WebUI 대안 중 가장 좋은 건?

떠나는 이유에 달려 있습니다. 팀용 셀프 호스팅 채팅 페이지라면 LibreChat(MIT, Docker). 회사 문서 검색이라면 Onyx. 컴퓨터 한 대에서 혼자, Docker 없이라면 모델을 직접 돌리는 LM Studio, Jan, Msty, text-generation-webui. GreenCube(Windows, 9.99유로 한 번)는 내 PC에 맞는 모델을 알아서 고릅니다.

Open WebUI는 아직 오픈 소스인가요?

라이선스가 이제 "Open WebUI License"입니다. BSD 방식의 조건에, 30일 동안 사용자가 50명 이하이거나, 서면 허가가 있거나, 기업 라이선스가 있는 경우가 아니면 브랜드 표시를 지우거나 바꿀 수 없다는 조항이 더해졌습니다. 그 전에 공개된 코드는 원래 라이선스를 유지합니다.

Docker 없는 Open WebUI 대안이 있나요?

있습니다. LM Studio, Jan, Msty, Chatbox, GreenCube는 일반 앱처럼 설치되고, text-generation-webui에는 압축을 풀어 실행하는 포터블 버전이 있으며, llama.cpp 서버에는 자체 웹 채팅 페이지가 있습니다.

모델을 직접 돌리는 Open WebUI 대안은?

LM Studio, Jan, text-generation-webui, llama.cpp, GreenCube는 별도 엔진 없이 모델을 돌립니다. LibreChat, Onyx, LobeHub, Chatbox는 Ollama 같은 엔진이나 클라우드 API에 연결합니다.

팀에 가장 좋은 대안은?

LibreChat(MIT)은 OAuth2, LDAP, 이메일 다중 사용자 로그인과 관리자 패널이 있습니다. Onyx는 회사 문서 전체 검색을 더하며, Business 플랜은 사용자당 월 20달러입니다. AnythingLLM의 Docker 버전도 다중 사용자를 지원합니다.

내 PC에서 돌아가는 나만의 AI

GreenCube는 내 컴퓨터에서 돌아갑니다. 사용 제한 없음, 구독 없음, 인터넷 없이도 작동. €9.99, 한 번 결제.
