짧은 답: LM Studio를 떠나려는 이유에 따라 다릅니다. 오픈 소스를 원한다면 Jan이 가장 가까운 대체재이고(Apache 2.0, 모델을 직접 돌림, Windows, Mac, Linux), Ollama(MIT)가 또 하나의 큰 선택지입니다. Intel Mac에서는 문서에 아직 Intel 지원이 나와 있는 Ollama. 휴대폰에서는 PocketPal AI나 Atomic Chat. 모델을 고르지 않고 Windows에서 쓰고 싶다면 GreenCube(9.99유로 한 번)가 내 PC에 맞는 AI를 골라 줍니다.

사람들이 LM Studio 대안을 찾는 이유

LM Studio는 좋은 앱입니다. 무료이고 업무용으로도 무료이며, 채팅 창과 로컬 OpenAI 방식 서버가 있고, PDF도 읽습니다(LM Studio). LM Studio 자체 페이지 기준으로 하지 않는 것:

  • 비공개 소스입니다. 읽어 보거나 직접 빌드할 수 있는 코드를 원한다면 다른 앱이 필요합니다.
  • 하드웨어 제한이 있습니다. Windows에서는 CPU가 AVX2를 지원해야 하고, Mac에서는 Apple 칩과 macOS 14 이상이 필요합니다(요구 사양). 오래된 PC와 Intel Mac은 쓸 수 없습니다.
  • 휴대폰 앱이 없습니다.
  • 모델은 직접 고릅니다. 모델을 잘 안다면 자유지만, 모른다면 이름만 잔뜩 늘어선 벽입니다.

떠나는 이유로 고르기

오픈 소스를 원한다면

Jan이 가장 가까운 대체재입니다. 모델을 직접 돌리고, PDF와 Office 파일을 읽고, 로컬 OpenAI 호환 API를 제공하는 데스크톱 채팅 앱으로, Apache 2.0 라이선스입니다(GitHub). Ollama(MIT)는 명령줄 엔진으로, 2025년 7월부터 Windows와 Mac에 데스크톱 채팅 창이 있습니다(Ollama). AnythingLLM(MIT)은 내 문서와 채팅하는 데 맞춰 만들어졌습니다.

Intel Mac을 쓴다면

LM Studio와 Jan은 둘 다 Apple 칩이 필요합니다(Jan). Ollama의 macOS 페이지에는 Apple M 시리즈와 x86(CPU만)이 macOS 14 Sonoma 이상으로 나와 있습니다(Ollama 문서). 느릴 것은 각오하세요. Intel Mac은 CPU만으로 모델을 돌립니다.

휴대폰에서 쓰고 싶다면

PocketPal AI(iPhone과 Android, MIT)와 Atomic Chat(iPhone과 Android, Apache 2.0)은 휴대폰 자체에서 모델을 돌립니다. AnythingLLM에는 Android 앱이 있습니다. 휴대폰에는 PC보다 작은 모델이 들어가므로 답이 더 단순합니다.

Windows를 쓰고 모델을 고르고 싶지 않다면

GreenCube는 그래픽카드와 RAM을 읽고 맞는 AI를 내려받은 뒤, 오프라인으로 채팅하고, PDF와 사진을 읽고, 플래시카드를 만들고, 그림을 생성합니다. 가격은 9.99유로 한 번이고 Windows 10과 11에서 돌아갑니다. Windows PC에 필요한 것, 실측.

LM Studio보다 빠를까?

이 앱들 대부분은 내부에서 같은 오픈 엔진인 llama.cpp를 돌리므로, 같은 PC에서 같은 모델이라면 속도는 앱이 아니라 대부분 하드웨어가 정합니다. 앱들을 나란히 놓고 시간을 재 보지는 않았으므로, 어느 쪽이 더 빠르다고 말하지 않겠습니다. 저희가 실제로 측정한 것은 실제 PC {{pcs}}대에서 돌린 GreenCube입니다:

2026년 10월 21일에 각 앱의 웹사이트, 문서, GitHub 페이지, 개인정보 페이지를 읽었고, 10월 23일에 Jan과 Ollama의 설치 페이지에서 Mac 지원을 다시 확인했습니다. 각 정보에는 출처 페이지 링크를 달았고, 페이지에 나와 있지 않은 것은 "명시 안 됨"이라고 적었습니다. 저희가 GreenCube를 만들기 때문에, 누구나 확인할 수 있는 사실만 담았고 앱 순위는 매기지 않았습니다. 매달 다시 확인하겠습니다.
