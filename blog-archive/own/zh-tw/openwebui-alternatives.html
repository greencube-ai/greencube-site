最好的 Open WebUI 替代方案，要看你為什麼想離開它。如果要給團隊用的自架聊天頁面，LibreChat（MIT，Docker）是最接近的替代品，Onyx 則多了跨公司文件的搜尋。如果只有你一個人在一台電腦上用，又不想碰 Docker 和另外的引擎，LM Studio、Jan 和 text-generation-webui 自己就能跑模型，Msty 則把本地引擎和雲端模型整合在同一個桌面應用程式裡。

我在做 GreenCube，它是這 11 個之一，所以我沒有替它們排名。每一項事實都來自該專案自己的網站、說明文件、價格頁面或授權條款，於 2026 年 10 月 21 日閱讀，連結附在每一列。頁面沒寫的地方，我們就寫「未說明」，我們也沒有把這些應用程式拿來互相做效能測試。

為什麼有人想找 Open WebUI 的替代方案

Open WebUI 是一個自架的聊天頁面，用 pip（Python 3.11）或 Docker 安裝。它通常架在 Ollama 這類引擎或相容 OpenAI 的 API 之上（文件）。它是很能幹的工具：能讀文件、可以「完全離線」執行，還有一個桌面應用程式，可選擇內建 llama.cpp 引擎（GitHub）。

大家離開的第一個原因是授權。它現在是「Open WebUI License」：BSD 式條款，外加一條規定你不得移除或替換「Open WebUI」品牌標示，除非你在任意連續 30 天內的終端使用者不超過 50 人、取得書面許可，或擁有企業授權（LICENSE）。

第二個原因是設定：要一台伺服器、Docker 或 Python 環境，再加上另外一個跑模型的引擎。第三個是合不合用。有些人想要更大的東西，有公司搜尋和權限管理；有些人想要更小的，例如在一台電腦上裝一個應用程式就好。

哪一個適合你？

給團隊用的自架聊天頁面

LibreChat 是最接近的替代品。它採用 MIT 授權，在 Docker 裡執行，附多使用者登入和管理面板，可以連接雲端 API 或你自己的引擎。如果主要工作是從公司的文件和應用程式裡回答問題，Onyx 就是為此而做的（MIT 的 Community Edition，或 Business 方案每位使用者每月 20 美元）。如果你最需要的是和文件對話，AnythingLLM 的 Docker 版很合適；LobeHub 則適合想要代理功能、又不介意它授權條件的人。

只有你自己，一台電腦，不用 Docker

LM Studio 和 Jan 像一般應用程式一樣安裝，自己就能跑模型，兩者都能提供本地的 OpenAI 式 API 給其他工具使用。Msty 混合了本地引擎和雲端模型。GreenCube 是我做的，只有 Windows 版：它會挑選並下載適合你電腦的模型，能讀 PDF 和照片、生成圖片，一次付清 9.99 歐元。

你喜歡自己動手，想要完全掌控

text-generation-webui 支援好幾種後端（llama.cpp、ExLlamaV3、Transformers），並表示執行時「零遙測」。llama.cpp 自己的伺服器給你一個瀏覽器聊天頁面，上面什麼都沒加。KoboldCpp 是另一個選擇，它是以 llama.cpp 為基礎的單一 .exe（GitHub）。

你想在手機上用同一個聊天

Chatbox 有桌面和手機 App，也能用 Ollama 跑本地模型。另外值得知道的是，Open WebUI 本身就能以網頁 App 的形式加到手機主畫面，所以光是這一點，未必是換掉它的理由。

本地模型在一般電腦上有多快？

不管你選哪個介面，速度都來自你的硬體，因為模型是在你的顯示卡或處理器上跑。我們在 {{pcs}} 台真實電腦上實測了 GreenCube；其他應用程式我們沒有在同樣的機器上測過。
