為什麼有人在找 Open WebUI 的替代品

Open WebUI 是一個用 pip（Python 3.11）或 Docker 安裝的自託管聊天頁面，通常執行在 Ollama 或相容 OpenAI 的 API 之類的引擎之上（文件）。它功能很強：能讀文件，能“完全離線”執行，還有一個可選內建 llama.cpp 引擎的桌面應用程式（GitHub）。我們最常聽到的另尋他處的原因有三個：

  • 授權條款。現在是“Open WebUI License”：BSD 式條款，外加一條不得刪除或替換“Open WebUI”品牌標識的條款，除非你在任意連續 30 天內的終端使用者不超過 50 人、獲得書面許可或擁有企業授權條款（LICENSE）。
  • 部署。需要一臺伺服器、Docker 或 Python 環境，外加一個單獨執行模型的引擎。
  • 是否合適。有人想要更大的（全公司搜尋、許可權管理），有人想要更小的（一臺電腦上一個應用程式）。

哪個適合你？

給團隊用的自託管聊天頁面

LibreChat 是最接近的替換：MIT 授權條款、Docker、多使用者登入和管理面板，可連線雲端 API 或你自己的引擎。如果主要任務是根據公司的文件和應用程式回答問題，選 Onyx（MIT 的 Community Edition，或託管版每使用者每月 20 美元）。如果你最需要的是和文件聊天，選 AnythingLLM 的 Docker 版本。如果你想要AI 代理，又不介意它的授權條款條件，選 LobeHub。

只有你自己，一臺電腦，不用 Docker

LM Studio 和 Jan 像普通應用程式一樣安裝，自己執行模型；兩者都能為其他工具提供本地 OpenAI 式 API。Msty 混合使用本地引擎和雲端模型。GreenCube（Windows）會挑選並下載適合你電腦的模型，能讀 PDF 和照片，還能生成圖片，一次付清 9.99 歐元。

你喜歡折騰，想要完全掌控

text-generation-webui 支援多個後端（llama.cpp、ExLlamaV3、Transformers），並表示執行時“零遙測”。llama.cpp 自己的伺服器給你一個沒有任何多餘東西的瀏覽器聊天頁面。基於 llama.cpp 的單檔案 .exe 程式 KoboldCpp 也是一個選擇（GitHub）。

你想在手機上用同樣的聊天

Chatbox 有桌面和手機應用程式，可以用 Ollama 執行本地模型。Open WebUI 本身也能作為網頁應用程式新增到手機主螢幕。

本地模型在普通電腦上有多快？

不管你選哪個介面，速度都來自你的硬體：模型執行在你的顯示卡或處理器上。我們在 {{pcs}} 臺真實電腦上測了 GreenCube（沒有在同樣的機器上測其他應用程式）：
