該選哪個 LM Studio 替代方案，要看你為什麼想換。想要開源的話，Jan 是最接近的替代品（Apache 2.0，自己就能跑模型，支援 Windows、Mac 和 Linux），另一個大咖是 Ollama（MIT）。用 Intel Mac 的話，Ollama 是文件上還列出支援 Intel 的那一個。在手機上，可以試試 PocketPal AI 或 Atomic Chat。

我在做 GreenCube，它是這九個之一，所以看我的意見時請把這點考慮進去；我沒有替它們排名。這些事實來自各應用程式自己的網站、說明文件或 GitHub 頁面，於 2026 年 10 月 21 日閱讀，10 月 23 日我們又在 Jan 和 Ollama 的安裝頁面上重新查核了 Mac 支援情況。「未說明」代表該應用程式的頁面沒有寫。我們沒有把這些應用程式拿來互相做效能測試。

為什麼有人想找 LM Studio 的替代方案

LM Studio 是個好應用程式。它免費，工作用途也免費，有聊天視窗和本地 OpenAI 式伺服器，還能讀 PDF（LM Studio）。想換的理由，都來自它自己的頁面。

它是閉源的，所以如果你想要能閱讀或自己編譯的程式碼，就得找別的。它也有硬體限制：在 Windows 上處理器需要 AVX2，在 Mac 上需要 Apple 晶片和 macOS 14 以上（系統需求）。這就排除了較舊的電腦和 Intel Mac。

它沒有手機 App。而且模型要你自己選，如果你懂模型，這是自由；如果你不懂，那就是一整面看不懂的名字。

依你想換的原因來挑

你想要開源

Jan 是最接近的替代品：一個自己就能跑模型的桌面聊天應用程式，能讀 PDF 和 Office 檔案，也能提供相容 OpenAI 的本地 API，採用 Apache 2.0 授權（GitHub）。Ollama（MIT）是命令列引擎，2025 年 7 月起在 Windows 和 Mac 上多了桌面聊天視窗（Ollama）。AnythingLLM（MIT）則以和你的文件對話為核心。

你用 Intel Mac

LM Studio 和 Jan 都需要 Apple 晶片（Jan）。Ollama 的 macOS 頁面列出 Apple M 系列和 x86（只能用處理器），需要 macOS 14 Sonoma 以上（Ollama 文件）。會很慢，因為 Intel Mac 只能靠處理器跑模型。

你想在手機上用

PocketPal AI（iPhone 和 Android，MIT）和 Atomic Chat（iPhone 和 Android，Apache 2.0）直接在手機上跑模型，AnythingLLM 也有 Android App。手機裝得下的模型比電腦小，所以回答會比較簡單。

你用 Windows，而且不想自己挑模型

GreenCube 就是為這種情況做的。它會讀取你的顯示卡和記憶體，下載適合的 AI，然後離線聊天、讀 PDF 和照片、做字卡、生成圖片。一次付清 9.99 歐元，支援 Windows 10 和 11。更多細節請看 Windows 電腦需要什麼配備。
