Does Apple Intelligence work offline?

Partly. Apple says Apple Intelligence processes requests on the device first, and sends more demanding ones to Private Cloud Compute, its own servers, which needs internet (Apple). The optional ChatGPT extension also needs internet. Apple doesn't publish which features always stay on the device, so the honest test is simple: turn on airplane mode and try the feature you care about.

Which Mac runs local AI well?

Apple chip, 16 GB+

The comfortable setup: an Apple chip shares its memory between processor and graphics, so the AI can use most of it.

Apple chip, 8 GB

Small models work; close other apps first, as on any 8 GB computer.

Intel Mac

Ollama on the processor only. Expect slow answers.

Any Mac

A model must fit in memory with room for the conversation; bigger isn't better if it doesn't fit.

We measure on Windows PCs, so we have no Mac speeds of our own; the rule that matters most is the same everywhere: a model that doesn't fit runs much slower.
